Keycloak is the open-source IAM backbone for countless applications, and provides single sign-on, strong authentication and user federation across organizations. We were part of the GitHub Secure Open Source Fund Session 3, participated in the three-week training and gained insights into how other projects handle incidents and implement security best practices. 67 projects were part of the training , so we received a lot of feedback.
