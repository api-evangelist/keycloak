# Keycloak

> Keycloak is an open source identity and access management solution for modern applications and services, providing single sign-on, identity brokering, user federation, and fine-grained authorization using OAuth 2.0 and OpenID Connect. This llms.txt was generated by API Evangelist from the catalog for keycloak; no llms.txt was published on the Keycloak site at the time of generation.

## APIs

- [Keycloak Admin REST API](https://www.keycloak.org/docs-api/latest/rest-api/): REST API for managing realms, users, clients, roles, groups, and identity providers across a Keycloak deployment.
